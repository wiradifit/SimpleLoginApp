# 🔐 Simple Login App

A clean, focused iOS authentication flow built with UIKit: form validation, loading and error states, and straightforward state management — the login screen done properly.

## Highlights

- Email/password sign-in form with inline validation
- Clear separation between view, validation logic, and state handling
- Loading, success, and error states handled explicitly

## Tech Stack

- **Language:** Swift
- **UI:** UIKit
- **Architecture:** lightweight MV-style state handling

## Getting Started

```bash
git clone https://github.com/wiradifit/SimpleLoginApp.git
open SimpleLoginApp.xcodeproj
```

Build and run from Xcode (`Cmd + R`).
